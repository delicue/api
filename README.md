# API Manager

## Prerequisites

- PHP ^8.4
- Composer
- Linux/MacOS

## How to Install and Run

It's complicated. Jk. Just have the prerequesites and run `php install`. Then `php serve` to run it.

## Features

- Generates API Key for user
- User can log in

## Upcoming features

- Associate user id with api key in database
